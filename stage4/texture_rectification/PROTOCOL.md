# Plane–texture consistency pilot

The primary hypothesis is directional. A depth-rectified texture should have higher residual error in generated images, and rectification should improve grid regularity more in real photos. The direct test compares images with the same caption, conditional on both images having at least one grid scored in camera and rectified views. Image-level residual and gain are medians across those windows. The residual is the mean of spacing error divided by 0.15 grid cycles, angular dispersion divided by 8°, and deviation from orthogonality divided by 20°. A positive paired effect favors the hypothesis for both the residual (generated minus real) and the gain (real minus generated). The classifier additionally uses the crossing connectivity error.

The secondary outcome is held-out pooled and generator-specific AUROC. Compare rectified residuals, gains, and coverage counts against a coverage-only model, an unrectified grid on RGB, and HOG computed on grayscale RGB input. Measure the incremental AUROC of depth features when added to each RGB baseline. Use class-balanced logistic regression with fixed L2 regularization and train-only standardization and mean imputation. Leave each generator out of training once and evaluate that generator against the held-out photographs. Use 2,000 percentile bootstrap draws over whole held-out caption groups and use the same draws for model deltas. The intervals reflect test-caption variability conditional on training and do not adjust for multiple comparisons.

The archive includes a transformed test split. Sample 100 complete six-source caption groups from its train split and 50 from its validation split, instance zero, seed 180280. Exclude any validation caption ID or normalized text found in the archive's train split. Check for identical JPEG bytes across selected groups. This pilot keeps the archive's 256 × 256 JPEG preprocessing and does not select by caption keywords for tiles.

UniDepth V2 ViT-S/14 estimates axial depth and pinhole intrinsics. Fit 13 overlapping square windows with trimmed SVD in back-projected camera coordinates. Accept approximately planar windows using the 85th percentile of the residual (2.5% of median patch depth), a minimum normal z component of 0.35, and a rectification extent check. For each accepted window, mask points that fail the plane residual threshold and apply the normal-derived rotation homography. Run OpenCV LSD in both views. Require two line families with at least three distinct offsets each, and score spacing, within-family dispersion, deviation from orthogonality, and local crossing support. The method targets visible rectangular grids such as tile seams. It can reject dense or obscured grids and can mistake unrelated straight edges for a grid. Report coverage on all held-out images, including images on which the score is missing.

The synthetic check uses a rendered grid with known geometry, the same grid paired with a wrong plane normal, and a warped grid on the correct plane. It tests the rectification and score ordering under controlled conditions.
